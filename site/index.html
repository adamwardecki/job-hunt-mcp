05 / Your next chapter starts here

Make a little room
for what’s next.

Bring the assistant you already use. JobHunt runs natively in Claude Code and Hermes Agent, with its own tracker to keep things together.

Requires Node 22.18+. No runtime npm dependencies.

1

Add the marketplace and install the plugin 

/plugin marketplace add adamwardecki/job-hunt-mcp
/plugin install job-hunt@job-hunt-mcp
2

The local tracker starts automatically and keeps its data in ~/.job-hunt/tracker.db

3

Let’s get to know you.

Your CV, preferences, and a five-role trial. You can pause and pick it up whenever you like.
